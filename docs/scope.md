# Scope Definition

## Scope Block (Constraints)
* **Duration:** 8 weeks (1 session/week + 5–8 hours/week work).
* **Team:** 1 person building.
* **Budget:** $0 / Free AI subscription only, no paid third-party APIs or infrastructure.
* **Delivery:** Live working demo on the final night.

## What is OUT of Scope
To ensure a successful working demo within 8 weeks, the following features are explicitly dropped:
1. **Automated Deadline Alerts:** No push notifications or automated emails for approaching deadlines.
2. **Paid Scraping / APIs:** No paid data scrapers or paid backends.
3. **Payment Gateways & Subscriptions:** The platform is 100% free; no payment integration.
4. **Mobile Native App:** Building only a mobile-responsive web application.
5. **Multi-language Support:** English interface only for the initial version.
